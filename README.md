# Madame Hairstylist

Website for a hair salon in Treviglio, Italy. Built as a client project.

## Live site
https://madame-hairstylist.pages.dev/

## Built with
- HTML
- CSS
- JavaScript (vanilla, no frameworks)

## Features
- Full service list organized by category (accordion)
- About section with the owner's own words
- Photo gallery of real work
- Opening hours table
- Parking and location info
- WhatsApp booking button
- Mobile menu and responsive layout
- Scroll reveal animations

## Notes
Built for a real client, Marta Bertin, hairstylist in Treviglio.
Content (services, prices, photos, bio) provided directly by the client.
First real client testimonial received after delivery.
